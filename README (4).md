# Дашборд менеджеров — Строительная лаборатория

Одностраничное веб-приложение (single-page HTML) для мониторинга показателей работы менеджеров по продажам. Данные загружены из Google Sheets (лист «Реестр копия») и встроены в файл — никаких серверов и интернет-соединения не требуется.

---

## Быстрый старт

1. Скачать файл `dashboard.html`
2. Открыть в любом современном браузере (Chrome, Edge, Firefox, Safari)
3. Войти под нужной учётной записью

## Функциональность

### Менеджер — личный дашборд

- **Ключевые показатели:** факт, план, % выполнения, дебиторская задолженность, количество оплаченных/неоплаченных сделок
- **График:** план vs факт по месяцам (январь / февраль)
- **Топ клиентов:** рейтинг с прогресс-барами по поступлениям
- **Реестр сделок:** полная таблица заявок с датой, компанией, типом работ, суммами и статусом оплаты
- **Фильтр периода:** Всего 2026 / Январь / Февраль

### Руководитель — общий дашборд + вкладки

- **Общий дашборд:**
  - Итоговые КПИ по компании (факт, план, ДЗ)
  - Карточки трёх менеджеров с ключевыми метриками и полосой выполнения плана
  - Столбчатый график по месяцам (суммарно)
  - Круговая диаграмма долей менеджеров в общем факте
  - Топ-8 клиентов компании
  - Сводная таблица дебиторской задолженности на апрель 2026 (итого 7 999 563 ₽)
- **Вкладки по каждому менеджеру:** полный персональный дашборд (идентичен виду менеджера)

## Данные

Источник: Google Sheets `Дашборд-менеджеры`, лист **Реестр копия**

Охватываемый период реестра: **январь–февраль 2026**

Дебиторская задолженность (апрель 2026) загружена из сводного листа:

| Менеджер | ДЗ |
|---|---|
| Александров С | 4 122 480,5 ₽ |
| Мартынов А | 3 772 583 ₽ |
| Синчагова С | 99 690 ₽ |
| **Итого** | **7 999 563,5 ₽** |

Столбцы реестра, используемые в дашборде:

| Поле | Описание |
|---|---|
| `date` | Дата заявки |
| `company` | Компания-клиент |
| `manager` | Ответственный менеджер |
| `test_type` | Тип испытания / работ |
| `lab` | Лаборатория (строительная / электро) |
| `plan` | Сумма по плану, ₽ |
| `fact` | Фактическое поступление, ₽ |
| `debt` | Долг по счёту, ₽ |
| `status` | Статус оплаты |
| `payment_date` | Дата оплаты |

## Структура файла

```
dashboard.html          ← единственный файл приложения
README.md               ← данная документация
```

Всё содержится в одном HTML-файле:
- встроенный CSS (тёмная тема, адаптив)
- встроенный JavaScript (авторизация, фильтры, графики, таблицы)
- встроенные данные (JSON-массив реестра)

Внешние зависимости — только шрифты Google Fonts (Oswald + Inter); при отсутствии интернета отобразятся системные шрифты, функциональность не пострадает.

---

## Обновление данных

Поскольку данные встроены в HTML, при обновлении таблицы нужно сгенерировать файл заново. Для этого:

1. Экспортировать лист «Реестр копия» в CSV или предоставить доступ к Google Sheets
2. Передать файл — приложение будет пересобрано автоматически с актуальными данными

---

## Технические требования

- Браузер с поддержкой ES6+ (Chrome 80+, Edge 80+, Firefox 75+, Safari 13+)
- Интернет нужен только для загрузки шрифтов при первом открытии
- Сервер не требуется — файл открывается локально
